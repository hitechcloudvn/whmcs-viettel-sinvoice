# Contributing / Đóng góp

> This is a commercial module. Contributions are accepted only through authorized customer, partner, or internal development channels.
> Đây là mô-đun thương mại. Chỉ tiếp nhận đóng góp qua các kênh khách hàng, đối tác hoặc phát triển nội bộ được ủy quyền.

**Repositories / Kho mã nguồn:** [GitHub](https://github.com/hitechcloudvn/whmcs-viettel-sinvoice) · [GitLab](https://gitlab.com/hitechcloudvn/whmcs-viettel-sinvoice)

---

## English

### Bug reports

Send reproducible reports to `support@photuesoftware.com` with:

- WHMCS version and PHP version.
- Module version.
- Sanitized WHMCS module log excerpts.
- Steps to reproduce.

Do not include production credentials, access tokens, full buyer PII, or raw Viettel API responses.

### Pull requests

- Follow WHMCS addon conventions and existing code style.
- Preserve direct-access guards.
- Preserve admin token validation for state-changing actions.
- Keep all logs and stored request/response data redacted.
- Run PHP lint and security grep checks before submission.
- Update `CHANGELOG.md` for customer-visible changes.
- Keep code comments and documentation bilingual (English and Vietnamese).

### Contact

General contact: `info@photuesoftware.com`.

## Tiếng Việt

### Báo lỗi

Gửi báo cáo có thể tái hiện đến `support@photuesoftware.com` kèm:

- Phiên bản WHMCS và PHP.
- Phiên bản mô-đun.
- Trích đoạn log module WHMCS đã che redaction.
- Các bước tái hiện lỗi.

Không đưa vào thông tin xác thực sản xuất, token truy cập, PII đầy đủ của bên mua hay phản hồi API Viettel gốc.

### Pull request

- Tuân thủ quy ước addon WHMCS và style code hiện có.
- Giữ nguyên guard chặn truy cập trực tiếp file.
- Giữ nguyên kiểm tra token quản trị cho mọi thao tác thay đổi trạng thái.
- Giữ toàn bộ log và dữ liệu yêu cầu/phản hồi đã lưu ở trạng thái được che redaction.
- Chạy PHP lint và các grep kiểm tra bảo mật trước khi gửi.
- Cập nhật `CHANGELOG.md` cho các thay đổi ảnh hưởng khách hàng.
- Giữ bình luận code và tài liệu song ngữ (Anh và Việt).

### Liên hệ

Liên hệ chung: `info@photuesoftware.com`.
